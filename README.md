# Param Ranjan — Portfolio

Interactive portfolio landing page built with React, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run lint
npm run build
```

Project imagery in the current landing page is intentionally abstract. Replace it with approved product screenshots or motion clips when those assets are available.

PP Mori, PP Mondwest, and PP NeueBit are available as local design experiments, but their font binaries are intentionally excluded from this public repository. Pangram Pangram's free license prohibits public website use and public redistribution. Add appropriately licensed font files to `public/fonts/` through a private deployment process before publishing these options.
